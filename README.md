# Шах и Флеш — MVP

Шахматы, где каждое взятие решается битвой: **покер → кубики → дуэль-шутер**, а в случайные моменты выскакивает **QTE**.

## Установка (Windows)
Скачайте `ShahIFlesh-Setup-<версия>.exe` со страницы [Releases](https://github.com/thirteenbtw/shah-i-flesh/releases) и запустите. Установщик спросит папку, создаст ярлыки на рабочем столе и в меню «Пуск». Удаление — через «Приложения» в параметрах Windows.

Установщик не подписан, поэтому Windows SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».

## Запуск без установки
Игре не нужны зависимости: можно открыть `index.html` в браузере или поднять локальный сервер:

```bash
node serve.js
```
и открыть http://localhost:5180.

## Сборка установщика
```bash
npm install
npm start          # игра в окне Electron
npm run dist       # установщик в dist/
```
Если сборка падает с `process failed 2` (бывает на дисках, где Windows не даёт запускать свежесобранные exe), соберите в папку на системном диске:
```bash
npx electron-builder --win nsis -c.directories.output=C:/temp/shah-dist
```

## Как играть
1. **Шахматы.** Вы — белые, бот — чёрные. Клик по фигуре → клик по клетке. Шаха нет, рокировки и взятия на проходе нет, пешка превращается в ферзя.
2. **Взятие = битва.**
   - **Покер:** 5 карт, один обмен (клик по картам или клавиши 1–5, затем Enter). Номер комбинации (пара = +1 … стрит-флеш = +8) добавляется к кубикам. Победитель покера бросает 3 кубика вместо 2 (в зачёт идут 2 лучших).
   - **Кубики:** итог = кубики + бонус покера + бонус QTE. Урон ×(0,6 + 0,05·итог), HP + 4·итог.
   - **Дуэль:** вид сбоку. A/D — бег, W — прыжок, мышь — прицел, ЛКМ — огонь. Сверху падают блоки-тетрамино: красная полоса показывает, куда. Блок на голову — урон, приземлившиеся блоки — укрытия, пули их разбивают. Полная линия блоков исчезает.
   - Победил атакующий — взятие состоялось. Проиграл — атакующая фигура погибает.
3. **QTE** (пробел, когда стрелка в зелёном сегменте):
   - в шахматах: ±1 к следующему броску кубиков;
   - в дуэли: успех — +20 HP и двойной урон на 3 с, провал — −15 HP. Пока идёт QTE, дуэль замедлена.
4. **Победа:** вражеский король пал в дуэли.

## Код
| Файл | Что внутри |
|---|---|
| `js/config.js` | Все числа баланса |
| `js/chess.js` | Доска, ходы, ИИ бота |
| `js/poker.js` | Колода, оценка руки, обмен карт ботом |
| `js/duel.js` | Шутер: физика, падающие блоки, ИИ бойца |
| `js/qte.js` | QTE-круг |
| `js/game.js` | Машина состояний: шахматы → покер → кубики → дуэль → итог |
| `js/render.js`, `js/main.js` | Отрисовка на Canvas и ввод |

Логика не зависит от отрисовки: её можно гонять в Node без браузера (`G.Game` с `botPlaysPlayer = true`).
